security setup

Sign-in protection

Email codes use {{ config.SECURITY_FROM_EMAIL if config.SECURITY_FROM_EMAIL is defined else 'security@moealturej.com' }} through {{ config.EMAIL_PROVIDER|upper if config.EMAIL_PROVIDER is defined else 'RESEND' }}. Discord OAuth is rate-limited and protected with state tokens. Bot token configured: {{ "yes" if discord_bot_enabled else "no" }}.

Login, signup, forgot-password, and product-key emails use Resend in production with RESEND_API_KEY. Keep REQUIRE_EMAIL_CODES=true for 6-digit security codes.
Auto key delivery uses RESELLING_PRO_API_KEY from .env only. Admin product settings store only the Reselling.pro base URL without the API key.
Discord login needs DISCORD_CLIENT_ID and DISCORD_CLIENT_SECRET. DISCORD_BOT_TOKEN is detected separately and is only for server/bot actions.
Auth routes and upload routes are rate-limited to avoid spam and Discord OAuth abuse.
Render-safe email delivery uses HTTPS through Resend, avoiding blocked SMTP ports. Use a verified sender/domain before going live.
